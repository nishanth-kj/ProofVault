# Web Setup Guide

The frontend is a Next.js application designed to interact with the ProofVault API and Solana smart contracts.

### 1. Installation

Navigate to the `web` directory and install dependencies:
```bash
cd web
npm install
```

### 2. Running Locally

Start the development server:
```bash
npm run dev
```
The web portal will be available at `http://localhost:3000`.
